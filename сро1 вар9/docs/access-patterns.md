# Паттерны доступа

| № | Операция | Redis-команда/подход | Приоритет | Ожидаемый результат |
|---:|---|---|---|---|
| 1 | Создать сессию | HSET + EXPIRE в pipeline | Высокий | ID сессии и запись с TTL |
| 2 | Получить сессию | HGETALL | Высокий | Поля сессии или пустой результат |
| 3 | Проверить активность | EXISTS | Высокий | true/false |
| 4 | Узнать TTL | TTL | Высокий | Секунды, -2 если ключ отсутствует |
| 5 | Продлить сессию | HSET + EXPIRE | Высокий | TTL обновлён |
| 6 | Обновить поле | HSET | Средний | Поле обновлено без замены всей записи |
| 7 | Logout | DEL | Высокий | Сессия удалена |
| 8 | Административный отзыв | DEL | Высокий | Доступ отозван |
| 9 | Найти сессии пользователя | SCAN + HGETALL + фильтрация | Средний | Список сессий пользователя |
| 10 | Массовая демонстрационная выборка | SCAN | Низкий | Количество активных сессий |

Пункты 9–10 предназначены для учебной демонстрации. Для крупной production-системы лучше поддерживать индекс пользователя → список session ID, согласованно обновляя его при создании и удалении.
